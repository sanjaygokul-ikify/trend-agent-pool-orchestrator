# Contributing to Agent Pool Orchestrator

## Code Style
- Python 3.11+
- PEP8 + Black
- Asynchronous I/O required

## Branching Strategy
Git flow with 2-week release cycles

## Testing
- Unit: pytest
- Integration: Locust stress tests

## Feature Proposals
Submit RFC in docs/rfcs/ with performance requirements

## Security
- BPF-based system call sandboxing
- gRPC token-based auth

## Community
Slack #agent-pool on CNCF workspace
Meetings: every Thursday 16:00 UTC
